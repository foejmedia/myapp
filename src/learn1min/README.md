# Learn in 1 Minute (`/learn-1-min`)

Daily Qur'an learning: a one-minute lesson each day, Qur'anic vocabulary, daily duas, surahs,
flashcards, quizzes, spaced-repetition revision and a personal notebook.

| Route | Screen |
| --- | --- |
| `/learn-1-min` | Dashboard (today's lesson, word of the day, streaks, activity, progress, revision, quick quiz) |
| `/learn-1-min/vocabulary` | 160 most frequent Qur'anic words (`?word=v12` opens one) |
| `/learn-1-min/duas` | 72 daily duas by category (`?dua=daily-1` focuses one) |
| `/learn-1-min/surahs`, `/surahs/[id]` | Surah list and ayah-by-ayah learning |
| `/learn-1-min/flashcards` | Flip cards, both directions, "learned / needs revision" |
| `/learn-1-min/quiz` | Daily challenge, multiple choice, reverse, fill-the-gap, matching, score history |
| `/learn-1-min/review` | Daily and weekly revision, difficulty, mastered, needs practice |
| `/learn-1-min/notebook` | Saved items and personal notes, filter and search |
| `/learn-1-min/account` | Profiles, export / import, delete |

Global search: **Ctrl/⌘ K** or **/**. Dark mode follows the site theme (`html.dark`).

## Content — verified sources only

Nothing religious is written by hand in this feature.

* **Vocabulary** — `data/vocabulary.json`, generated by `node scripts/build-learn-data.mjs`.
  Roots, dictionary forms and occurrence counts come from the **Quranic Arabic Corpus** morphology
  (corpus.quran.com, via the corrected mirror `mustafa0x/quran-morphology`). The word form,
  transliteration, word-by-word meaning, word audio and example ayat (Saheeh International) come
  from the **Quran.com API v4**. Arabic is stored as `text_qpc_hafs` — the KFGQPC encoding the
  site's `UthmanicHafs` font is built for (the same font Read Quran uses). Don't switch to
  `text_uthmani`: its silent-alif mark (U+06DF) shows as a dotted circle in this font. Each example is cross-checked: the Corpus word at
  a location must match Quran.com's word at that location, otherwise it is dropped. The meaning shown
  is Quran.com's meaning *in that ayah*, and the UI says so.
  The Corpus asks that its data is credited with a link to corpus.quran.com — keep the source note.
* **Chapters** — `data/chapters.json` (names, meanings, ayah counts) from Quran.com, same script.
* **Duas** — the site's own `public/data/duas/*.json`, used as stored. Audio is offered only for
  Qur'anic duas (the ayah recitation); hadith duas have no verified recording yet.
* **Surah text** — loaded at runtime from `/api/quiz/content` (the Quiz feature's validated
  Quran.com loader). If it fails, nothing partial is shown.
* **Recitation** — Mishary Rashid Alafasy (Quran.com CDN); word audio from Quran.com.

Regenerate the data: `node scripts/build-learn-data.mjs` (needs network; takes about a minute).

## Storage — local development layer

`store/repository.ts` defines two seams:

* `ProgressRepository` — load / save / subscribe a profile's progress document
* `AuthAdapter` — profiles and sign-in

`store/local.ts` implements both with `localStorage` (keys `l1m:profiles`, `l1m:data:<id>`).
Profiles are device-local and have **no password** on purpose: browser storage cannot protect an
account. To add real accounts and sync, implement the two interfaces against a backend and swap
them in `store/index.ts`; no component changes are needed.

The progress document (`store/model.ts`, version 2) is validated on every load. The first release's
data (`learn-1-min:v1`) is migrated into the first profile so learned days and streaks are kept.
All changes go through the pure `apply(state, action)` reducer.

## Learning logic

* `lib/items.ts` — item ids (`v:`, `d:`, `s:`), the interleaved daily lesson path, word of the day
* `lib/srs.ts` — SM-2 style scheduling (Again / Hard / Good / Easy), mastered at a 21-day interval
* `lib/quiz.ts` — question generators; answers are always the data itself, distractors are other
  real items, and look-alike options (same letters without vowels, same meaning) are never paired
* `lib/stats.ts` — every dashboard number, derived from saved progress (no placeholder figures)

## Tests

`npx vitest run src/learn1min` — data integrity (every example contains its word, counts, ordering),
question validity, SRS intervals, lesson path, reducer, migration.
